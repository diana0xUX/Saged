# Lead-handling playbook

How to convert a DM into a booking — for Diana, Koritsa, and anyone else replying on saged.club channels.

> **Working principle**: this audience prefers warm conversation over cold checkout. The DM IS the funnel. Respond like a human; the booking follows naturally.

## Response SLA

| Channel | Target response time | Why |
|---|---|---|
| WhatsApp | < 4 hours during the day, by next morning at the latest | WhatsApp users expect speed; >12h reply hurts conversion |
| Telegram | < 4 hours | Same |
| Instagram DM | < 12 hours | Slower expectations on IG, but don't let it drift |
| Email | < 24 hours | Lowest urgency channel |

If you can't reply within target, send a short "we got your message, will reply by [time]" within 30 min. That keeps the lead warm.

## The 5-stage flow

A typical lead conversation goes:
1. **Acknowledge** — within minutes if possible
2. **Answer** — their explicit question, plus any obvious adjacent question they didn't ask
3. **Invite to commit** — offer specific slot, not "what works for you?"
4. **Send booking link** — Cal.com or manual
5. **Confirm after payment** — emoji + short note, set expectations for the workshop day

Each stage below has copy templates. **Copy is starting points, not scripts** — adapt to the person.

## Stage 1 — Acknowledge

**Goal**: human warmth, no friction. Don't dump info yet.

### RU template
```
Привет! Спасибо, что написали 🪷
Сейчас расскажу. Один момент.
```

### UA template
```
Привіт! Дякую, що написали 🪷
Зараз розповім. Хвилинку.
```

### EN template
```
Hi! Thanks for reaching out 🪷
Let me get you the details — one moment.
```

Use this when you need >30 minutes to respond properly. Buys time without ghosting.

## Stage 2 — Answer

**Goal**: give the info they need to decide. Don't oversell. Plain language.

If they asked "сколько стоит / how much":

### RU
```
Курс — 60 €. Это две встречи по 2 часа:
🪷 первая — лепим ваше изделие руками
🪷 вторая, через неделю — глазурь и обжиг

В цену входит вся глина, инструменты, все обжиги, чай. Группа маленькая — до 6 человек.

Ближайший четверг — [DATE]. Какое время удобнее: 12:00, 15:00 или 19:00?
```

### UA
```
Курс — 60 €. Це дві зустрічі по 2 години:
🪷 перша — ліпите виріб руками
🪷 друга, за тиждень — глазур і випал

У ціну входить уся глина, інструменти, усі випали, чай. Група маленька — до 6 осіб.

Найближчий четвер — [DATE]. Який час зручніше: 12:00, 15:00 чи 19:00?
```

Notice: ends with a **specific question**, not "let me know if you have any questions." That's the difference between a stalled DM and a moving one.

## Stage 3 — Invite to commit

**Goal**: surface intent. If they're warm, give them a path. If cold, give them space.

### Warm signal (they asked specific questions, replied within a day, used positive language)

### RU
```
Отлично! Тогда забронируем вас на [DATE], [TIME]. Скину сейчас ссылку на оплату 🪷
```

### UA
```
Чудово! Тоді забронюємо вас на [DATE], [TIME]. Зараз надішлю посилання на оплату 🪷
```

### Cold signal (they're asking exploratory questions, taking 2+ days between replies)

### RU
```
Без давления — пишите, когда будете готовы 🪷
Если хотите, могу прислать пару фоток с прошлого четверга — как там было.
```

### UA
```
Без тиску — пишіть, коли будете готові 🪷
Якщо хочете, можу надіслати кілька фоток з минулого четверга — як там було.
```

The "without pressure" framing is doing real work — it removes the awkwardness so they don't ghost out of politeness.

## Stage 4 — Send booking link

**Goal**: friction-free payment. Make the link match the slot you already discussed.

### Option A — Cal.com direct link (preferred)
```
Вот: https://cal.com/saged-club/ceramics

Просто выберите дату + слот, который мы обсуждали — и оплата картой. Я подтвержу как только увижу 🪷
```

UA equivalent — same but в українську.

### Option B — Manual / Stripe payment link (if Cal.com is being weird)
Generate a Stripe payment link in dashboard, send it directly. Use this for:
- Special prices (gift certificates, friend-discounts, group bookings)
- People who can't/won't use Cal.com
- Anyone who's expressed friction with the Cal.com flow

### Option C — "Pay on arrival" (last resort)
For someone who's a known/repeat customer or referred by someone trusted. Just confirm the slot manually in Cal.com's admin. Risk: ~5% no-show. Use sparingly.

## Anti-patterns to avoid

- **Long copy-paste replies** — feels like a bot. Personalize at least one sentence.
- **"Let me know if you have any questions"** — dead-end phrase. Always close with a specific question or invite.
- **Sending the Cal.com link before they've expressed clear intent** — pushes them off-channel too early. Save the link for Stage 4.
- **Replying after midnight** — even if you're up, schedule the message for 9am. Late replies signal desperation.
- **Apologizing for delays** — adds friction. Just respond directly: "Утром не было связи. Слот на [DATE] в [TIME] свободен — забронируем?"

## What to log

For every booking that comes via DM, record (in a notes app, spreadsheet, or wherever):
- **Name + handle** of the lead
- **Channel** they came through (WhatsApp/Telegram/IG/email)
- **Time-to-first-reply** (from us)
- **Number of messages** before they paid
- **What question(s) they asked** before committing

After 10 bookings via DM, patterns emerge — you'll see which questions actually drive conversion, which can be pre-answered on the landing page.

## When to escalate / hand off

Most leads should be handled by whoever's covering DMs that day. Hand off to Diana or Koritsa for:
- Custom requests (private group, gift certificates, special date)
- Anyone asking about teaching their own class in the studio
- Complaints or refund discussions
- Press / collab inquiries

A simple "Передаю Диане, она ответит в течение дня" / "Передаю Діані, вона відповість протягом дня" works.
