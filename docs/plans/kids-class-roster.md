# Kids class · реестр заявок и расписание

**Issue:** [#115](https://github.com/diana0xUX/Saged/issues/115) · **Эпик:** [#91](https://github.com/diana0xUX/Saged/issues/91) (kids campaign)
**Назначение:** одна таблица для отслеживания всех заявок от родителей. Когда наберётся группа 4-6 человек одного формата + языка — назначаем дату класса.

---

## Два формата

| Формат | Цена | Длительность | Кто пришёл | Когда |
|---|---:|---|---|---|
| **детский** | €25 | 1.5 ч | ребёнок один (6-10 лет) | будний вечер или суббота утром |
| **семейный** | €50 | 2 ч | родитель + ребёнок | суббота / воскресенье |

_Цены — ориентир. Подтвердить с Дианой перед первой группой._

## Правило назначения класса

Класс ставим в расписание, когда на одном формате + одном языке набирается **4-6 заявок**. Меньше 4 — ждём, больше 6 — открываем вторую группу или выносим в очередь на следующую дату.

Это значит: один лид сам по себе не двигает дату. Двигает группа.

### Статусы (что значит)

| Статус | Значит |
|---|---|
| **запрос** | только что написали, ещё не ответила |
| **в списке** | ответила, формат и возраст подходят, ждём группу |
| **записан** | назначена конкретная дата класса |
| **оплачено** | пришёл Stripe / перевод |
| **провёл** | пришёл на класс |
| **отменил** | отказался / не пришёл |

Поток: `запрос` → `в списке` → (когда набралась группа) → `записан` → `оплачено` → `провёл`.

## Раздел по языкам — для решения "когда назначать"

Когда нужно понять, набралась ли группа — посчитать строки со статусом `в списке`, разбитые по формату + языку:

```
RU · детский   ▢▢▢▢▢▢   (нужно ≥4)
RU · семейный  ▢▢▢▢▢▢
UA · детський  ▢▢▢▢▢▢
UA · сімейний  ▢▢▢▢▢▢
```

Когда любая строка набралась — пишем всем родителям из этой строки одно сообщение с двумя-тремя вариантами дат, собираем согласие, ставим дату, переводим всех в статус `записан`.

## Что делегируется Корице

Корица берёт на себя:
- Добавляет новые строки, когда приходит лид в WhatsApp
- Меняет статус (`запрос` → `в списке` → `записан` → `провёл`)
- Заполняет дату класса и пометку об оплате после звонка от Дианы / Stripe
- Ведёт колонку "Примечания" (аллергии, особенности ребёнка)

Диана сохраняет за собой:
- Решение о цене и формате
- Подтверждение даты группы (Корица предлагает, Диана подтверждает)
- Отправку Stripe-ссылки / приём перевода
- Окончательное решение, открывать ли новую группу

## Когда переезжать в Google Sheets

Эта таблица в маркдауне работает, пока:
- Лидов меньше ~15
- Заполняет только Диана со своего лэптопа
- Корица ещё не подключена

Переезжаем в Google Sheets, когда:
- Корица готова взять часть работы (нужен редактирование с телефона)
- Лидов больше 15-20 (становится тяжело искать)
- Захочется графиков / суммарных подсчётов

**Миграция (10 минут):**
1. Открыть `docs/plans/kids-class-roster.md` в редакторе
2. Скопировать таблицу
3. Открыть Google Sheets → новая таблица
4. Вставить (Sheets автоматически распознает столбцы)
5. Поделиться ссылкой с Корицей (`@ko_hasi` в Telegram) с правом редактирования
6. На этот файл в репо поставить пометку: «жить переехала в Google Sheets, ссылка: ...» и оставить как архив

## Что НЕ кладём в этот файл

- Полные номера телефонов и фамилии — в публично-доступных коммитах не нужны. Использовать `wa.me/34...` (часть номера ОК) или инициал фамилии. _(Репо приватный после 2026-05-29, но привычку лучше держать чистой — на случай если когда-то откроется обратно.)_
- Внутренние комментарии про лидов («странно общается», «возможно не родитель») — это в WhatsApp, не в репо
- Финансовые детали (выручка, итоги месяца) — в `finances/` (gitignored)
