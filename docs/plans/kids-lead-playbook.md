# Kids leads · как сортировать

**Issue:** [#115](https://github.com/diana0xUX/Saged/issues/115) · **Связано:** [`kids-class-roster.md`](kids-class-roster.md) (таблица) · [`intake-templates.md`](intake-templates.md) (шаблоны первого ответа · на ветке dev/111)

Реестр (`kids-class-roster.md`) — это **где** живут лиды.
Этот файл — **как** с ними обращаться, когда они появляются.

## Один экран — вся логика

```
        НОВЫЙ DM
        (IG или WhatsApp)
            │
            ▼
   Перенести в WhatsApp ───► (всегда; IG = только первый контакт)
            │
            ▼
   Ответить в 24 часа ─────► шаблон из intake-templates.md
            │
            ▼
   Спросить 3 must-have:
   • имя ребёнка
   • возраст
   • формат (детский / семейный)
            │
            ▼
   ┌────────┴────────┐
   │                 │
ВСЁ есть         НЕТ инфы
   │                 │
   ▼                 ▼
🟢 в списке      🟡 запрос
   │                 │
   │              (один follow-up
   │               через 48 ч → 7 дн)
   │                 │
   │                 ▼
   │              🔴 молчит → закрыть
   ▼
(ждём пока наберётся 4-6 одного формата + языка)
   │
   ▼
🟣 записан → 🟣 оплачено → 🟣 провёл
```

## 4 ведра — всё, что нужно держать в голове

Каждый лид в любой момент сидит **ровно в одном ведре**. Каждое утро 5 минут — глянуть, что в каком ведре и нужно ли двигать.

| Ведро | Что значит | Что делать |
|---|---|---|
| 🟡 **запрос** (новый) | Только что написал, ещё нет 3 must-have | Ответить шаблоном + задать недостающие вопросы. Лимит ожидания: 48 ч |
| 🟢 **в списке** | Format + age + контакт есть. Ждём группу. | **Ничего**. Проверять по пятницам: набралась ли группа из 4-6 |
| 🟣 **записан / оплачено / провёл** | Уже на конкретную дату | Напомнить за 24 ч до класса. После класса — попросить отзыв (опционально) |
| 🔴 **молчит** | Не отвечает 7 дней + один follow-up уже отправлен | Один последний пинг. Нет ответа ещё 7 дн → статус `отменил`, не возвращаемся |

**Что НЕ ведро**: «возможно интересно», «потом подумаю», «может в следующий раз». Это всё → 🟡 `запрос` пока не разрешится в одну из четырёх позиций выше.

## Сначала перевести в WhatsApp

Любой DM в Instagram — **первое же сообщение** переносим в WhatsApp. Причин три:

1. Stripe-ссылка для оплаты приходит в WhatsApp, не в IG
2. Скроллить переписку в WhatsApp проще, особенно с телефона
3. Когда Корица подхватит — будет один канал, не два

**Скрипт переноса (RU):**
> Спасибо, что написали! Давайте перенесём в WhatsApp — там удобнее с расписанием и оплатой: wa.me/34605543300

**Скрипт переноса (UA):**
> Дякую, що написали! Давайте перенесемо до WhatsApp — там зручніше з розкладом та оплатою: wa.me/34605543300

После переноса в IG ничего не пишем — продолжаем в WhatsApp. Если родитель забудет — пинг через 24 ч ОК.

## Дневной ритм (15 минут в день)

| Когда | Что | Сколько |
|---|---|---|
| Утро | Открыть IG inbox + WhatsApp. Новые DM? Перенести IG → WhatsApp | 5 мин |
| Утро | Ответить на всё новое со вчера. Обновить статус в реестре | 5 мин |
| **Пятница** утром | Посмотреть ведро 🟢. Набралась группа 4-6 одного формата + языка? Если да — выбрать дату, написать всем | 5 мин |
| **Пятница** утром | Проверить ведро 🟡: кто там сидит уже 48 ч без ответа? Один follow-up каждому | _входит в 5 мин выше_ |

**Это всё.** Не пытаемся отвечать ВСЕМ в реальном времени — это съест дни. Утренняя пачка работает, потому что родители планируют, не «прямо сейчас», и 24 ч задержки нормальные.

## Когда писать Дане (или Корице) сюрприз-сообщение

Не в дневной пачке, а **сразу** — три случая:

1. Кто-то напрямую спрашивает «можно ли прямо в субботу прийти» — может быть конкретный шанс конверсии в тот же день
2. Семейный формат: родитель уточняет цену — €50 не подтверждена в KNOWLEDGE.md ([вопрос](#когда-эскалировать-фергусу))
3. Лид от кого-то с большим IG-аккаунтом (1000+ подписчиков) — потенциальная UGC/обзор-возможность

## Когда эскалировать Фергусу

Эти моменты — стоп-сигнал, не пытаться решать в голове:

| Триггер | Действие |
|---|---|
| Набралось 4-6 одного формата + языка | «Фергус, помоги назначить группу — вот лиды» |
| Родитель спрашивает что-то, на что нет готового ответа (corporate, подарочный сертификат, доступность для ребёнка с особенностями) | «Фергус, набросай ответ» |
| Цена семейного формата не подтверждена в живом разговоре | «Фергус, €50 за семейный — норм или меняем?» |
| Поток заявок ≥10/день | Триггерит [#110](https://github.com/diana0xUX/Saged/issues/110) — автоматизацию ответов |
| Лид присылает текстовое полотно с историями ребёнка | «Фергус, что отвечать?» — можно не открывать пока время не появится |

## Что **не делать**

- ❌ **Не назначать дату, пока в группе меньше 4** одного формата + языка. Иначе будет соло-класс, который Корица не возьмёт по экономике.
- ❌ **Не обещать фото-отчёт** с ребёнка в Stories / Reels без явного согласия родителя. Спросить в момент бронирования: «можно ли использовать фото?» — записать ответ в Примечания.
- ❌ **Не миксовать семейный + детский на один день**. Семейный — это родитель работает за столом тоже. Если есть свободные места — посадить семьи в семейный слот, детей в детский.
- ❌ **Не переписываться больше 7 сообщений до получения 3 must-have**. Если родитель не отвечает на простые вопросы — отметить 🟡 и идти дальше.
- ❌ **Не возвращаться к 🔴 закрытым лидам** через месяц с «привет, ещё актуально?». Лучше потратить эти минуты на новый трафик.

## Cross-channel: один человек, два DM

Бывает: родитель написал в IG, потом ещё в WhatsApp («вы видели моё сообщение?»). Два DM, один человек, один лид в реестре.

**Правило**: WhatsApp — это операционная правда. В реестре — одна строка, контакт = WhatsApp. В IG отвечаем только «давайте сюда» и закрываем там.

Дубликат лида = баг в реестре. Если такое случилось — слить две строки в одну, оставить раннюю дату запроса.

## Дизайн-аналогия (для Дианы)

Думать про это как про **Figma-канбан**:

- 🟡 запрос = `Inbox`
- 🟢 в списке = `Ready for design review`
- 🟣 записан = `In progress`
- 🟣 оплачено = `Approved`
- 🟣 провёл = `Shipped`
- 🔴 молчит = `Won't fix`

Каждое утро смотришь Inbox, двигаешь карточки. Не пытаешься фиксить каждый тикет в моменте. Пятница — это спринт-планнинг: что из `Ready for design review` идёт в `In progress` на следующей неделе.
