Rules — never break these

Height: always 62px. Never taller, never shorter. This is a hard constraint — content below the nav uses padding-top: 62px to clear it.
Background: rgba(249,244,237,.96) + backdrop-filter:blur(10px). Semi-transparent warm cream, blurs content scrolling beneath. Never solid white, never dark.
Logo: SVG /assets/images/logo-saged-club.svg, height 32px. On sub-pages without the SVG, use stacked text: SAGED in orange, CLUB in ink. No other logo variants.
Links: 14px, weight 500, color var(--muted) (#6b5f54). Hover: ink color + sand background pill (border-radius:8px). No underlines. No bold on regular links.
CTA pill: always the rightmost item. Background var(--orange) (purple for handpan = #8a60a8, terracotta for main = #9f4d2d as pill). Min-height 40px, padding 0 20px, border-radius 999px. One pill only — never two pill-style buttons in the nav.
Back link: sub-pages (handpan, materials-lab, etc.) add a ← Saged Studio link before the CTA pill. Color: var(--clay) (#6e4a8c) or terracotta. Never a full URL — always readable label.
Scroll shadow: JS adds .scrolled class when window.scrollY > 4 → box-shadow: 0 2px 24px rgba(42,37,32,.08). Required on every page.
Mobile: below 768px, links hide, burger button appears (height:40px, border 1.5px solid var(--line), border-radius:8px). Tapping opens links as vertical dropdown with border-radius:18px card. Never a full-screen overlay.
Position: always position:fixed, z-index:50. Never sticky — sticky breaks on iOS Safari inside scroll containers.

JS — required scroll + burger behaviour

// Scroll shadow
window.addEventListener('scroll', () => {
  document.querySelector('.gn').classList.toggle('scrolled', window.scrollY > 4)
}, {passive: true})

// Mobile burger
const menuButton = document.querySelector('.gn__burger')
menuButton?.addEventListener('click', () => {
  const open = menuButton.getAttribute('aria-expanded') === 'true'
  menuButton.setAttribute('aria-expanded', String(!open))
  document.querySelector('.gn__links').classList.toggle('open', !open)
})
